Résilience 2045 est une architecture énergétique pour la France. L'électrification y est complétée par le biométhane issu de la biomasse résiduelle (méthanisation, pyrogazéification, méthanation des surplus renouvelables). Elle retire durablement du carbone de l'atmosphère, par le biochar et par le stockage du CO₂ biogénique concentré.
